## Описание движка KV v2

**KV (Key-Value) Engine v2** — это движок хранения секретов в Vault с поддержкой версионирования данных. Позволяет безопасно хранить, обновлять и удалять секреты с историей изменений.

* Хранение в формате ключ → значение
* Версионирование: каждая запись имеет ревизии
* Поддержка soft delete и undelete

---

## Основные возможности

* **Версионирование секретов**: можно откатить изменения к предыдущей версии.
* **Soft Delete**: удалённые секреты можно восстановить.
* **Audit Logging**: все операции записываются для аудита.
* **Политики доступа**: разграничение прав на чтение, запись, удаление.

---

## Пример конфигурации

```hcl
# enable-kv-engine.sh
vault secrets enable -path=secret kv-v2

# Пример политики для доступа к KV v2
path "secret/data/backend/*" {
  capabilities = ["read", "list"]
}

path "secret/data/frontend/*" {
  capabilities = ["read", "list"]
}
```

---

## Использование в пайплайнах

* Чтение секрета:

```bash
vault kv get -field=password secret/data/backend/db
```

* Запись секрета:

```bash
vault kv put secret/backend/db password="S3cretPass!"
```

* Получение предыдущей версии:

```bash
vault kv get -version=2 secret/backend/db
```

* Удаление и восстановление:

```bash
vault kv delete secret/backend/db
vault kv undelete secret/backend/db
```

---

## Рекомендации по безопасности

* Использовать минимальные права через Vault Policies.
* Не хранить секреты в Git или в конфигурационных файлах.
* Включить audit logging для всех операций.
* Настроить backup и snapshot для защиты от потери данных.
