## Восстановление Unseal

**Цель:** восстановить доступ к кластеру Vault после перезапуска или аварийного состояния.

**Шаги:**

1. Получить сохранённые ключи unseal (Shamir keys).
2. Выполнить команду на каждом ноде Vault:

```bash
vault operator unseal <ключ1>
vault operator unseal <ключ2>
vault operator unseal <ключ3>
```

3. Проверить статус:

```bash
vault status
```

* Статус должен быть `Sealed: false`.

## Восстановление из снапшота

**Цель:** восстановить данные Vault после сбоя или потери данных.

**Шаги:**

1. Подготовить snapshot-файл, созданный ранее через `vault operator raft snapshot save <файл>`.
2. На новой ноде Vault остановить сервис:

```bash
systemctl stop vault
```

3. Восстановить snapshot:

```bash
vault operator raft snapshot restore <файл>
```

4. Запустить Vault:

```bash
systemctl start vault
```

5. Проверить статус:

```bash
vault status
```

* Должны вернуться все секреты и политики.

## Bootstrap кластера

**Цель:** заново инициализировать кластер Vault после полного сброса или новой установки.

**Шаги:**

1. Запустить инициализацию Vault:

```bash
vault operator init -key-shares=5 -key-threshold=3
```

* Сохранить все сгенерированные ключи unseal и root-token в безопасном месте.

2. Распределить ключи unseal между администраторами.
3. Выполнить unseal на каждом сервере кластера (см. раздел «Восстановление Unseal»).
4. Проверить статус кластера:

```bash
vault status
```

* Статус `Sealed: false`, все ноды активны и синхронизированы.

5. Применить политики и роли из `security/vault/policies/` и `security/vault/roles/`.

6. Настроить интеграции с приложениями и CI/CD, проверить доступ к секретам.
