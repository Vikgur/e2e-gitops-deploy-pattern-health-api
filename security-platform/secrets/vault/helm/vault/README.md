Этот каталог содержит конфигурацию Helm для Vault.

При развертывании используется официальный Helm-чарт для Vault:

https://github.com/hashicorp/vault-helm

В этом репозитории хранятся только:

- производственные значения (values.yaml)
- значения для разработки (values-dev.yaml)
- конфигурация маршрутизации Istio и резервного копирования (templates/)

Развертывание выполняется через Helmfile.
